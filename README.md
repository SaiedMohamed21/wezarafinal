 الخطوات الوحيدة اللي انتِ ستقومين بها
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

الخطوة 1 ▶ تشغيل قاعدة البيانات في SSMS:
  ① شغّلي: database/01_database_schema.sql
  ② شغّلي: database/02_organizations_data.sql  (992 جمعية)
  ③ شغّلي: database/03_fundraising_data.sql    (بيانات جمع المال)

الخطوة 2 ▶ إعداد كلمة المرور:
  - انسخي ملف .env.example واحفظيه باسم .env
  - افتحيه وعدّلي: DB_PASSWORD=كلمة_مرورك

الخطوة 3 ▶ في Command Prompt داخل مجلد backend:
  npm install
  node server.js

الخطوة 4 ▶ افتحي المتصفح على:
  http://localhost:3000
